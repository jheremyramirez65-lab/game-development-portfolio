# Recicle & Launch

![Captura principal](Capturas/gameplay.png)

## Descripción

Juego arcade de física y clasificación de residuos.  
Arrastra cada residuo desde el lanzador y suéltalo apuntando al basurero correcto (Orgánico, Plástico o Papel). Hay barreras móviles que obligan a calcular la trayectoria.

- **Objetivo:** Conseguir 12 aciertos antes de que se acabe el tiempo o las vidas.
- **Mecánica principal:** Arrastre + lanzamiento con física (gravedad y rebotes).

## Género
Arcade / Física / Educativo

## Controles
- Arrastrar con mouse o dedo hacia abajo y soltar para lanzar
- Evitar las barreras móviles

## Tecnologías utilizadas
- HTML5 Canvas
- JavaScript puro
- Física simple (gravedad + fricción)

Física básica, detección de colisiones, feedback visual y diseño de HUD claro.

## Mejoras futuras
